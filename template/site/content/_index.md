description: The code analysis rules of this organization for AL projects, one ruleset per level and stage.
---

A **rulebook** is the set of code analysis rules this organization agrees on for its AL projects. It is published as one ruleset per **level** (how strict) and **stage** (the moment the ruleset is used, such as the editor or a CI build), each at its own URL, so a project points at an endpoint instead of copying rules around.

This site shows the action of every rule on every level and stage, sets up an AL project in three steps, and lets you propose a change: put cells in the cart and open them as an issue in the rulebook repository.

It is for the AL developer who wants the right ruleset in a project, and for the maintainer who decides which rules apply where.
