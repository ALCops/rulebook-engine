What the cells mean

A cell is the action the endpoint of that level and stage gives the rule. The marker says which input decided it, in the order the generator applies them:

  • O an entry of overrides.json (point at the badge for its position in the file, from 0)
  • the twins rule of the settings
  • the stage file
  • no marker: the level file, or the analyzer default
  • Q the quarantine of the stage, for an id no level file names

Click a cell, or press Enter or Space on it, to put a change in the cart (the grid is one Tab stop: the arrow keys move between its cells, Home and End go to the ends of a row): an action, Reset on an override cell (remove the override), Release on a quarantine cell. The cart opens the change set as an issue in this repository; the Apply Rulebook Change workflow applies it when you may push. {{ with .data.docsUrl }}More in the documentation.{{ end }}

To use an endpoint in an AL project, see Set up an AL project.
