Set up an AL project

Point an AL project at a ruleset of this rulebook: one file per stage, downloaded once, kept up to date by the URL it includes.

An AL project keeps one file per stage in .rulebook/: the skeleton of its level, which includes the endpoint, with the project exceptions in its rules. The init script downloads the files of a level, for example:

Invoke-WebRequest {{ $data.initScriptUrl }} -OutFile Get-RulebookSkeletons.ps1
./Get-RulebookSkeletons.ps1 -BaseUrl {{ $base }} -Level {{ $first.slug }} -Ref {{ $data.engineRef }}

Then point VS Code at the default stage with "al.ruleSetPath": ".rulebook/default.ruleset.json" and AL-Go at the CI stage with "rulesetFile": ".rulebook/ci.ruleset.json". Details: docs/al-project.md. The levels and stages of this site, machine-readable: {{ $base }}/rulebook.json.
