Set up an AL project

Point an AL project at a ruleset of this rulebook: one file per stage, downloaded once, kept up to date by the URL it includes.

An AL project keeps one file per stage in .rulebook/: the skeleton of its level, which includes the endpoint, with the project exceptions in its rules. Pick a level below, run its two commands of the init script from the AL project root (the folder with app.json), then point VS Code at the default stage and AL-Go at the CI stage. Details: docs/al-project.md.
