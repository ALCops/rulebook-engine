{{ .Title }}

What the levels, stages and cells of this site mean, and how a change from the cart reaches the rulebook.

Levels

A level says how strict the rules are, as one ruleset per stage: {{ range $i, $level := $data.levels }}{{ if $i }}, {{ end }}{{ $level.name }}{{ end }}. A level is based on another level and changes the action of some rules: it keeps every action of that level unless its own file sets another (a level based on none starts from the analyzer defaults). The level page lists what it changes. {{ with $docs.levels }}Levels and starting points{{ end }}

Stages

A stage is a moment a ruleset is used, such as editing in VS Code, a CI build or a build against the next major version: {{ range $i, $stage := $data.stages }}{{ if $i }}, {{ end }}{{ $stage.name }}{{ end }}. A stage can adjust the result of every level for that moment, and every level is published once per stage, so an AL project can point the editor at one endpoint and its build at another; the setup page has the URLs. {{ with $docs.alProject }}The rulebook in an AL project{{ end }}

Cells

A cell of the matrix is the action one endpoint gives one rule: Error, Warning, Info, Hidden or None. Its marker says which input decided it: a badge O for an override{{ with $docs.overrides }} (overrides){{ end }}, a ring for the twins rule{{ with $docs.twins }} (per-tenant extension or AppSource){{ end }}, a dot for the stage file, a badge Q for the quarantine of a new id{{ with $docs.quarantine }} (quarantine){{ end }}, and no marker for the level file or the analyzer default. {{ with $docs.dashboard }}The dashboard{{ end }}

Changes

Click a cell to put a change in the cart. Submit on GitHub opens a prefilled issue form in the organization repository{{ with $data.repository }} {{ . }}{{ end }}, and Create files the issue. When you may push there, the Apply Rulebook Change workflow turns the issue into a pull request (or a commit, as the settings say), and the site shows the change once it is merged and published. {{ with $docs.changingARule }}Changing a rule{{ end }}
