# Dnn. Title, one sentence in noun or imperative form

- **Status:** Accepted | Superseded by Dnn (date) | Partly superseded by Dnn (date)
- **Date:** YYYY-MM-DD

- **Decision:** what was decided, in one sentence.
- **Rationale:** why.
- **Rejected:** the alternatives and the reason each one lost.
- **Consequences:** what the decision forces elsewhere in the design.
- **Affects:** work package issues that implement or depend on it.
