# D28. Identity is one `name`; the slug names every file, URL, selector and key

- **Status:** Accepted
- **Date:** 2026-10-01

- **Decision:** a level or stage is identified by its `name`. The slug is the lowercased name, must match `^[a-z0-9-]+$` and must be unique within its array. Every file name, endpoint URL, skeleton, quarantine file, override selector value and `resolved.json` key uses the slug; prose, the `name` property of generated files and the index page use the name as written (`vNext`, `CI`, `Essential`). Endpoint URLs are `<baseUrl>/rulesets/<level>.<stage>.ruleset.json`, and `<baseUrl>/rulesets/<level>.ruleset.json` for the `default` stage: the literal `default` is dropped only in `rulesets/`; everywhere else it is written. Shipped names are not edited, because the shipped file name is the key the update workflow overwrites; a different name is an alias level (`basedOn` the shipped one, empty delta) and the shipped entry is removed from the published list. Renaming changes URLs and is the documented breaking change.
- **Rationale:** the `L<n>` ids existed only to let names change without changing URLs, and the price was two identities in every document, selector and script. The alias recipe gives renames for free with one identity. Lowercase slugs make the published artifacts case-insensitive in practice. The suffix-less default URL is the common case and reads as the plain level.
- **Rejected:** separate `id` and `name` fields (what this entry removes); slug only, no display casing (`vnext` in every doc); the default stage spelled out in URLs (`essential.default.ruleset.json` for the most used endpoint); dropping the suffix everywhere (an empty selector value and a nameless quarantine file).
- **Consequences:** the shipped stage names change from `dev`, `cicd`, `nextmajor` to `default`, `CI`, `vNext` (slugs `default`, `ci`, `vnext`); the shipped level slugs are `essential`, `recommended`, `strict`, `complete`; `L1` to `L4` disappear from every file, URL, key and script. Matrix columns are `Default`, `CI`, `vNext`. Skeletons always carry the stage suffix (`skeletons/strict.default.ruleset.json`) and the AL project files are `.rulebook/default.ruleset.json`, `.rulebook/ci.ruleset.json`, `.rulebook/vnext.ruleset.json`, which closes O6 (one file per stage). The template's "how to rename a level" becomes "how to alias one". Supersedes the id half of D15 and the URL pattern of D21; refines D4.
- **Affects:** WP02 to WP11, WP13; `docs/rulebook/` and `tools/rulebook/` in full; the template's `README.md` and `docs/`.
