# D44. The write token secret is GHTOKENWORKFLOW in the AL-Go format

- **Status:** Accepted
- **Date:** 2026-10-07

- **Decision:** the workflows that write to an organization rulebook repository take their token from the secret `GHTOKENWORKFLOW`, holding a personal access token or the compressed GitHub App JSON `{"GitHubAppClientId":"...","PrivateKey":"..."}` exactly as AL-Go does, and the name can be changed with the `ghTokenWorkflowSecretName` setting.
- **Rationale:** most organizations that run a rulebook build their apps with AL-Go and already have this secret, often as an organization secret backed by a GitHub App with the Contents, Pull requests and Workflows permissions the update needs; the same name and format mean no second secret, no second app and one page of setup documentation that matches AL-Go's. The update must write `.github/workflows/`, which `GITHUB_TOKEN` can never do, and a pull request opened with `GITHUB_TOKEN` starts no workflow, so a token from a secret is needed anyway. The setting covers an organization whose AL-Go secret has another name or that wants a separate one; the workflow reads it in a settings step and passes `secrets[<name>]` to the action, which exchanges the App JSON for a one-hour installation token limited to the repository.
- **Rejected:** a Rulebook-specific name such as `RULEBOOK_TOKEN` (a second secret and, for an App, a second installation for the same permissions, with nothing gained; still possible through the setting); `GITHUB_TOKEN` (cannot write workflow files, its pull requests run no checks, and organizations can forbid Actions to open pull requests); a GitHub App owned by ALCops (every organization would have to trust and install a third-party app with write access to its repositories).
- **Consequences:** `ghTokenWorkflowSecretName` (default `GHTOKENWORKFLOW`) is in the settings schema; `UpdateRulebookSystemFiles.yaml` resolves the secret by that name; `Rulebook.GitHub` implements the PAT passthrough and the App exchange; the user page `docs/ghtokenworkflow.md` in `ALCops/rulebook` explains the App and PAT setup and links AL-Go's. The scan, change and apply workflows reuse the same secret and lookup. Open decision O4 is closed.
